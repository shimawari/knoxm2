# Lame School
Modified Theme School for MAN 2 Knox-enrolled devices.

## Short Caution
To clarify, Lame School is **NOT** designed to remove all of Theme School features but rather as a replacement of it but with a less stricter version.
**DO NOT** use Lame School for malicious intent (e.g cheating, playing games, etc). Use this for educational purposes only.
The developers are **NOT** responsible for the actions committed by the users.

## How to Install and Use

  1. Make sure that the original theme school is not installed in order to get Lame School installed smoothly.
  2. Install Lame School only outside of school hours.
  3. Disable Knox policies by using the "App default" method in Lame School's app settings.
  4. Enjoy!
