# Lame School
Modified Theme School for MAN 2 Knox-enrolled devices,

## Short Caution
To clarify, Lame School is **NOT** to uninstall Theme School as a whole but rather as a replacement of Theme School but with a less stricter version.
And **DO NOT** use Lame School for malicious intent (e.g cheating, playing games, etc). Use this for educational purposes.
The developers are **NOT** responsible for the rules that are violated by the users.

## How to Install
  1. Make sure that the original theme school is not install in order Lame School is installed smoothly
  2. Install Lame School only **OUTSIDE** of school hours.
  3. Disable Knox policies by switching app default in Lame School settings.
  4. Enjoy!
